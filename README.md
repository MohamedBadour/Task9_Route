# Assignment 9 - Sticky Notes (Mongoose + JWT)
1. MongoDB running on `mongodb://127.0.0.1:27017` (database `sticky-notes`).
2. `npm install` then `npm start` (works with defaults; optional `.env.example` for custom values).
3. Import `Assignment9.postman_collection.json`. The Login request saves the token automatically; replace `NOTE_ID` in the notes URLs with a real id.

Bonus: `bonus.js` (LeetCode - Longest Common Prefix).
